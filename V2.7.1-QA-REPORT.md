# MaterialYardage v2.7.1 — Breadcrumb UI Fix

## Change
Removed the duplicate, top-of-page `.breadcrumbs` strip that appeared above the main content. The highlighted stray breadcrumb in the deployed screenshots was a second breadcrumb generated outside the content container.

## New breadcrumb structure
- One `.crumbs` breadcrumb per content page.
- Guide pages: Home / Guides / Article
- Reference pages: Home / Reference / Article
- Category calculators: Home / Category / Calculator
- Calculators hub: Home / Calculators
- Guides hub: Home / Guides
- Reference hub: Home / Reference
