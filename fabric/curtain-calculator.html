Curtain Fabric Calculator

Estimate fabric for flat or gathered curtains using finished width, fullness, drop, hems and an optional vertical pattern repeat.

Calculate curtain fabric

How it works

Flat fabric width required is track width multiplied by fullness. The number of drops is rounded up using usable fabric width as the width of each drop. Each drop length includes finished drop plus hems; if a pattern repeat is entered, the cut length is rounded up to a whole repeat.

Consider return, overlap, heading style, pair split, lining, fabric direction and track installation before ordering. This simple estimator does not replace a curtain maker's cut plan.
