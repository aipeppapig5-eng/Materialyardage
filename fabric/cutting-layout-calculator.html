Plan a simple rectangular cutting layout

Layout logic

The tool compares pieces-across and row counts for the allowed orientations, then selects the orientation with the shorter estimated fabric length. This is a simple row layout, not a general-purpose nesting optimizer.

Only enable rotation if the fabric grain, nap, print direction and pattern permit it. Different piece sizes and irregular shapes need a manual cutting plan.
