# MaterialYardage v2.8 QA Report

## Scope
Accessibility and mobile-navigation hardening on top of v2.7.1.

## Changes
- Added one keyboard-accessible Skip to content link to indexable HTML pages.
- Added `id="main-content"` to the primary `<main>` landmark.
- Converted visual breadcrumbs to semantic `<nav aria-label="Breadcrumb">` landmarks.
- Added `aria-current="page"` to the active primary navigation item.
- Improved mobile navigation so the existing navigation can scroll horizontally instead of wrapping into an awkward multi-line header.
- Added breadcrumb wrapping protection for long guide titles.
- Added mobile typography/result sizing adjustments.
- Added `prefers-reduced-motion` support.
- Preserved existing calculator JavaScript, AdSense publisher configuration, analytics, canonical URLs, sitemap and content architecture.

## Automated QA
- 39 HTML files checked.
- 39/39 contain exactly one skip link and main-content target.
- 39/39 have no duplicate `.crumbs` blocks.
- 38/38 non-404 pages have exactly one active primary-nav item; 404 intentionally has no active section.
- JSON-LD parsing: PASS.
- Internal local link targets: PASS.
- JavaScript syntax: PASS.
